Install and use Lanruj

How to install Lanruj, keep it up to date or remove it, and how to find your way around the app.

Installing

Lanruj comes as an AppImage and as a Flatpak. Both run on Debian 13, Ubuntu 24.04 and Linux Mint 22 or newer, Fedora, openSUSE Leap 16, Arch and other distributions at least as recent. You only need one of them.

AppImage

The AppImage is a single file that carries everything it needs; nothing else has to be installed.

  1. Download the AppImage and put it where you want to keep it, for example in a folder called Applications in your home folder.
  2. Make it executable: right-click it, open Properties, then Permissions, and allow running it as a program. In a terminal, the same is chmod +x Lanruj-0.4.3-x86_64.AppImage.
  3. Double-click it.

At every start, Lanruj adds itself to the applications menu, so after the first start you can open it from there. If you move the file, the menu entry follows it at the next start.

Flatpak

Flatpak must be installed, with Flathub added. Most distributions have both; on Debian, run sudo apt install flatpak and follow the steps on flathub.org/setup. Then download the Flatpak and install it from a terminal, in the folder where you saved it:

  • for you only, without a password: flatpak install --user lanruj.flatpak
  • for all users of the computer, with your administrator password: flatpak install lanruj.flatpak

Flatpak downloads the GNOME runtime from Flathub if it is missing. Double-clicking the file works only where GNOME Software is installed. If Lanruj does not appear in the applications menu after your first Flatpak installation for yourself, log out and back in; on Cinnamon (Linux Mint), pressing Ctrl+Alt+Esc is enough.

Updating

AppImage: download the new version, start it once, then delete the old file. Flatpak: download the new lanruj.flatpak and install it the same way as the first time. Your journal and your settings stay as they are.

Uninstalling

Uninstalling removes the app, not your journal. If you turned them on, first turn off Start with the computer and Remember the password on this computer in Preferences, so nothing is left in your startup programs or in your keyring.

AppImage: delete the file, then its menu entry and icons:

  • rm ~/.local/share/applications/io.github.ThinkRoot99.Lanruj.desktop
  • rm ~/.local/share/icons/hicolor/scalable/apps/io.github.ThinkRoot99.Lanruj.svg
  • rm ~/.local/share/icons/hicolor/symbolic/apps/io.github.ThinkRoot99.Lanruj-symbolic.svg

The settings stay in ~/.config/lanruj, ~/.local/state/lanruj and ~/.cache/lanruj; delete these folders too if you do not want to keep them.

Flatpak: run flatpak uninstall --delete-data io.github.ThinkRoot99.Lanruj, then flatpak uninstall --unused to remove the GNOME runtime if no other app needs it. If you installed Lanruj for you only, add --user to both commands.

Your journal stays in ~/.lanruj, and the backups in Documents/Lanruj - copii or in the folder you chose. Delete them only if you are sure you no longer need what you wrote.

Using Lanruj

The first time you open Lanruj, it asks for the language, the paper, the font and whether to encrypt the journal. You can change all of them later in Preferences. The guide in the app (F1) explains everything step by step; here is the short version.

Day, week and month pages

Each day has its own page, and the week and the month have theirs. You write short lines in the field at the bottom: start a line with . for a task, o for an event or - for a note, then press Enter. Add * after the sign to mark something important, or ! for an idea. Ctrl+Enter ticks a task when it is done. The future log holds what is further ahead.

Migration

In the evening, Ctrl+M takes you through the tasks you did not finish, one by one. For each, you decide: move it to the next day, schedule it for a later date, drop it or leave it where it is.

Journal

The journal is for writing at length, one page per day. You can use headings, lists, quotes, colours and different fonts, and link a piece of text to a day, a task or Tracking. Ctrl+Shift+O starts a new entry with the current time.

Tracking

Tracking follows your habits and activities, your sleep and your work days, month by month, with charts and sheets you can print.

Index, search and notes

The Index keeps the days and pages you want to find again; Ctrl+I adds the day you are looking at. Ctrl+F searches everywhere. Ctrl+N opens a note: a small slip for a quick idea, which stays on every page until you delete it.

Backups, lock and encryption

Lanruj makes backups of your journal on its own. In Preferences, under Security, you can lock the app with a password or a PIN, lock it when the screen locks, and encrypt the whole journal.

Keyboard shortcuts

Almost everything can be done from the keyboard. Ctrl+? shows all the shortcuts in the app, and the keyboard shortcuts page explains each one.
